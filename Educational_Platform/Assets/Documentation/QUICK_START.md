```bash

ollama serve
```

1. Open your project: `Educational_Platform`
2. Go to `Assets/Scenes` (create if doesn't exist)
3. Create new scene: Right-click → Create → Scene → name it `GameScene`
4. Save the scene

### Step 3: Quick Setup (2 minutes)
1. **Create Canvas:**
   - Right-click Hierarchy → UI → Canvas

2. **Add one Text element (for testing):**
   - Right-click Canvas → TextMeshPro → Text
   - Name it `StatusText`
   - Set position: Bottom center
   - Set text: "Loading..."

3. **Create GameFlow object:**
   - Right-click Hierarchy → Create Empty
   - Name it `GameFlow`

4. **Add Components:**
   - Select GameFlow
   - Inspector → Add Component → QuestionFlowManager
   - Drag StatusText to the `statusText` field

5. **Press Play!**

## 📝 Understanding the New Architecture

### Three Concepts to Know

1. **Step** = A lesson within a challenge
   - Example: "Addition with single digits (0-5+5)"
   - Goal: Get 5-streak to complete
   - Customizable: Set StreakGoal, MasteryTarget, UltimateChallenge

2. **Challenge** = A unit (like a chapter)
   - Example: "Addition" has Steps 1, 2, 3
   - Contains: Multiple steps, navigation, completion tracking

3. **Player** = The learner
   - Tracks: Current subject, challenge, step
   - Stores: Mastery per step, streak in current step
   - Persists: Saved to Supabase (async, resumes from cache on next load)

### Example Data Flow
```
Player: Math > Addition > Step 1
  ↓
GenerateQuestion(player, step) → "What is 3 + 2?"
  ↓
Player answers: "5"
  ↓
Evaluate(player, step, answer) → "Correct! +0.04 mastery"
  ↓
Streak: 0/5 → 1/5
  ↓
[Repeat 4 more times]
  ↓
Streak: 5/5 → Step Complete!
  ↓
Auto-advance to Step 2
```

## 🔧 How to Customize

### Change the Starting Step
Edit `Core/PlayerDataManager.cs` — change the default step ID used when creating a new player.
See `CURRICULUM.md` for the step UUID constants, or use `ChallengeDataManager.STEP_ADDITION_1_ID`.

### Add a New Challenge or Subject
Follow the checklist in `Assets/Documentation/CURRICULUM.md` → "Adding a New Challenge".
The core edit is in `ChallengeDataManager.cs` → `InitializeHardcodedChallenges()`.

### Add a New Question Type
1. Create: `Core/DragDropQuestion.cs` implementing `IQuestion`
2. Update: `OllamaQuestionGenerator.cs` to return it
3. Update: `QuestionDisplay.cs` to display it
   ```csharp
   if (question is DragDropQuestion ddq)
       DisplayDragDrop(ddq);
   ```

## 🎓 Key Classes to Know

### Player
```csharp
_player.CurrentSubject = "Math";
_player.CurrentChallenge = "Addition";
_player.CurrentStep = 1;
_player.GetMasteryForStep("Math", "Addition", 1) // 0.75f
_player.AdvanceToNextStep(); // Move to step 2
```

### Step
```csharp
step.StreakCurrent = 5; // Player got 5 in a row
step.IsFullyComplete // True if streak=5 AND ultimate complete
step.GetCurrentPhase() // StreakBuilding or UltimateChallenge
```

### Challenge
```csharp
challenge.GetStep(1); // Get step number 1
challenge.GetFirstIncompleteStep(); // Find next unfinished step
```

### IQuestion
```csharp
question.QuestionType // "multiple_choice"
question.CheckAnswer("5") // true or false
question.SkillFocus // "Addition"
```
